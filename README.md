# NFL Pick'em Live

Mobile-first straight-up NFL Pick'em tracker, currently configured for Week 2 of the 2026 season.

The previous World Cup application is preserved on branch `backup-world-cup-2026-20260920`.

## Features
- 16-game Week 2 card
- Lawrence's picks and MNF tiebreaker
- Live/manual result entry
- Automatic pool standings recalculation
- Editable pool entries saved locally in the browser
- Payout display

GitHub Pages continues to use `index.html` on `main`.
